# Technical content lock

Preserve source numbers, percentages, dates, periods, labels, factual claims, uncertainty markers, professional conclusions, recommendations, and citations unless the user supplies an authoritative correction.

Allowed changes: order, headings, explanation, examples that introduce no new facts, vocabulary that preserves meaning, emphasis, formatting, and calls to action around the result.

If an apparent technical problem is detected, preserve the source and flag `possible_source_issue`. Do not repair from persona knowledge or model memory.
